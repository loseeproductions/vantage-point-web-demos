# VPW Niche Demo Sites

Six niche demo templates for Vantage Point Web Design cold outreach.

## Files
- `restaurant.html`
- `plumber.html`
- `landscaper.html`
- `hvac.html`
- `hair-salon.html`
- `auto-repair.html`

## Usage
Each file is a self-contained HTML demo. Upload a prospect-customized version to:
`demos/{slug}.html` → served at `{slug}.vantagepointwebdesign.us` via the activate webhook.
